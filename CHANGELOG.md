# Журнал изменений SmartDo

Записи ведутся по сессиям. Самые свежие — сверху.

---

## Сессия 2026-11-19

Работа над версией **2.0** (ветка `v2.0`).

### Раздел «Настройки» — большая переработка
- Экран **«Настройки»** приведён к единому списку в порядке:
  **Приложение → Изменить тему → Перенос данных → О приложении**.
- Новый экран **«Приложение»** (`AppSettingsScreen.kt`) с переключателями:
  - **Звук** — звуковой сигнал при действиях (`soundEnabled`);
  - **Вибрация** — тактильный отклик при нажатиях (`hapticsEnabled`).
  - Флаги прокинуты через `CompositionLocalProvider` (`LocalSoundEnabled` / `LocalHapticsEnabled`)
    и реально глушат звук/вибрацию во всех местах `CategoryDetailScreen`.

### Тема оформления
- Из шапки **всех пяти экранов** (Списки, Архив, Напоминания, Статистика, Детали категории)
  убран быстрый переключатель темы (солнце/луна).
- Новый экран **«Изменить тему»** (`ThemeScreen.kt`) с выбором:
  **Системная / Светлая / Тёмная** (галочка у активного), расширяемый под будущие темы.
- В `TaskViewModel` метод `toggleTheme(isDark)` заменён на `setThemeMode(mode)`.

### Перенос данных (бэкап)
- Блок **«Резервное копирование»** перенесён из экрана **«Статистика»** в
  **Настройки → «Перенос данных»** (`DataTransferScreen.kt`).
- Экспорт/импорт переведены на **файлы** через Storage Access Framework:
  - **Экспорт в файл** — `ACTION_CREATE_DOCUMENT`, имя вида `SmartDo_Backup_ГГГГ-ММ-ДД.json`;
  - **Импорт из файла** — `ACTION_OPEN_DOCUMENT`, чтение `.json` и восстановление данных.
  - Разрешения на хранилище не требуются.

### Мелочи
- В меню экрана «Списки» пункты **«Статистика»** и **«Архив»** поменяны местами
  (теперь Статистика идёт первой).
- Исправлена ошибка сборки: убраны «висячие» импорты в `MainActivity`,
  ссылавшиеся на ещё не созданный `AppSettingsScreen`.

### Новые возможности — Этап 1 (Работа со списками)
- **Поиск по всем задачам** — новый экран (`SearchScreen.kt`), иконка 🔍 в шапке «Списков».
  Ищет по названию, описанию, подзадачам и названию списка.
- **Сортировка и фильтр списков** — кнопка сортировки в шапке «Детали списка» и умных списков:
  **Вручную / По сроку / По приоритету / По алфавиту** + переключатель
  **«Скрывать выполненные»**. Выбор сохраняется (`taskSortMode`, `hideCompleted` в `AppData`).
  Оформлено отдельной модальной панелью снизу (`SortFilterSheet.kt`) с иконками
  в цветных кружках и подсветкой выбранного.
- **Отмена удаления** — после удаления задачи внизу появляется Snackbar **«Отменить»**
  (метод `undoDelete()` возвращает задачу из архива на место).
- **Подтверждение удаления** — новый тумблер в «Приложение» (`confirmDeleteEnabled`):
  если включён, свайп влево спрашивает подтверждение перед удалением.
  Прокинут через `LocalConfirmDelete`.

### Новые возможности — Этап 2 (Планирование)
- **Повторяющиеся задачи** — в диалоге задачи (при наличии срока) выбор повтора:
  **Нет / День / Неделя / Месяц / Год** (`repeatRule` в `Task`).
  При выполнении повторяющейся задачи автоматически создаётся следующий экземпляр
  со сдвинутым сроком (подзадачи сбрасываются), уведомление перепланируется.
  На карточке показывается маркер «🔁 …».
- **Календарь** — новый экран (`CalendarScreen.kt`), пункт «Календарь» в меню «Списков».
  Месячная сетка с навигацией по месяцам, точками в днях с задачами, выделением
  сегодняшнего дня и выбранного; снизу — список задач выбранного дня
  (с переключением, редактированием и удалением с отменой).
