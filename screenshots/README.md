# Скриншоты приложения SmartDo

Поместите сюда скриншоты вашего приложения для отображения в главном README.md:

* `categories.png` — Главный экран «Списки» (светлая/тёмная тема)
* `reminders.png` — Экран «Напоминания» (дни рождения, знаки зодиака, фильтры)
* `archive.png` — Экран «Архив»
* `edit_task.png` — Окно редактирования задачи с подзадачами
* `calendar.png` — Экран «Календарь» с месячной сеткой
* `search.png` — Экран глобального поиска
* `stats.png` — Экран «Статистика» с круговым прогрессом
* `settings.png` — Экран «Настройки» (тема, язык, звук)
